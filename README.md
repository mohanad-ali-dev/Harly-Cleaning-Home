# Harly Cleaning Home

https://mohanad-ali-dev.github.io/Harly-Cleaning-Home/

A modern and responsive landing page for a professional home cleaning service.

## About the Project

Harly Cleaning Home is a frontend landing page designed for a home cleaning business.

The project focuses on creating a clean, modern, responsive, and user-friendly interface that presents the company's services and encourages visitors to contact or book a cleaning service.

This project was built as part of my frontend development practice and portfolio.

## Features

- Responsive design for different screen sizes
- Modern and clean user interface
- Hero section with clear call-to-action
- Services section
- About/company section
- Contact and booking form
- Interactive form elements
- Responsive navigation
- Semantic HTML structure
- Custom CSS styling
- Basic JavaScript interactions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Responsive Design

The landing page is designed to work across:

- Mobile devices

- Desktop screens
